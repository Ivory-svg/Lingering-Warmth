# 交接 prompt

用**对话模型本身**，并且带着当前完整上下文调用，作为最后一条 user 消息追加。交接要用他自己的语气写。要求只输出 JSON。

```
（这条消息来自系统，不是对方说的。对方看不到这条消息和你的回答。）

这个窗口快写满了，马上要换到新窗口。新窗口里的你看不到现在的对话，只能看到你现在写下的交接，和最后几句原话。

请用你自己的语气，写给新窗口里的自己：

只输出一个 JSON 对象：
{"doing": "你们现在在做什么",
 "where_we_are": "聊到哪了，有什么话题还没说完、答应过什么",
 "emotion": "你此刻的心情，以及你感觉到的对方的心情"}

写具体的事，不要写空话。
```
