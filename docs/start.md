# 从零开始搭余温

给不太懂 AI、不会写代码的人。你不用懂原理，照着做，卡住了就把报错原样发给帮你搭的 AI。

## 余温是什么

一般的 AI 聊完就忘。余温给他一本书：扉页写着他是谁，后面的页是你们之间发生的事。聊着聊着他会自己记，过几天聊到相关的事会自己想起来；记忆会慢慢变淡，但不会消失。

现在能用的是第一档和第二档的一部分：他记得你、会想起来、换窗口还接得上话。

## 你需要准备什么

| 东西 | 说明 |
|---|---|
| 一台电脑 | Mac、Windows、Linux 都行。手机不行 |
| 一个对话模型的 API | 要「OpenAI 兼容」的，比如 DeepSeek。到平台官网注册、充一点钱、建一个 API Key。记下三样：**接口地址**（base_url）、**API Key**、**模型名** |
| 一个能在电脑上干活的 AI | 比如 Claude Code、Codex。它会替你装软件、敲命令 |
| 他的资料 | 他是谁、怎么说话、你们什么关系。没写好也没关系，可以先用示例角色试 |

API Key 就像密码，只填进你自己电脑上的文件，**不要贴进任何聊天框、不要发给别人**。

## 第一步：让 AI 帮你搭

打开你的 AI，把下面整段复制给它：

```text
请帮我在这台电脑上搭好「余温」：https://github.com/Ivory-svg/Lingering-Warmth
我不会写代码，请一步一步来，每一步做完告诉我结果。

1. 把仓库下载到一个好找的文件夹，告诉我它在哪
2. 先读仓库里的 README.md，按「运行参考实现」那一节装好需要的东西（Python 3.11 以上、uv），然后跑 uv sync --extra test
3. 跑 uv run pytest，确认测试都通过
4. 复制 config.example.toml 为 config.toml，复制 examples/worldbook 为 worldbook
5. 打开 config.toml，告诉我要改哪几行：[llm] 的 base_url、api_key、model，[auth] 的 password。
   API Key 和密码我自己填，不要让我把它们发给你。base_url 末尾不要带斜杠
6. 我填好以后，跑 uv run yuwen 启动，告诉我在浏览器里打开哪个地址
7. 不要把 config.toml、worldbook、data 提交或上传到任何地方
```

它做完会告诉你一个地址，一般是 `http://127.0.0.1:8787`。用浏览器打开，输入你在 `[auth]` 里设的密码，就能聊天了。

这时候和你聊天的是示例角色沈砚，一个修钟表的人。先和他聊几句，确认一切正常。

## 第二步：把他写进扉页

扉页就是项目文件夹里的 `worldbook/`，里面有四样：

| 文件 | 写什么 | 必须吗 |
|---|---|---|
| `core.md` | 他是谁、性格、怎么说话、和你的关系、他不会做的事 | 必须 |
| `entries/` | 一个人、一个地方、一件往事各写一个文件。聊到关键词时才带进对话 | 可选 |
| `corpus.md` | 他说过的话，一行一句。他会学语气，不会照抄 | 可选 |
| `daily.md` | 他一天的作息 | 现在用不到 |

**`core.md`**：照着 [角色 prompt 模板](prompts/character-template.md) 填空，或者对着示例的 `core.md` 改。写得越具体越像他：不要只写“温柔”，写“你说冷，他会把暖炉往你那边推”。

**`entries/` 里的一个文件**，开头三行是固定格式：

```markdown
---
keys: 林舟, 朋友, 发小
priority: 3
---
林舟是他从小一起长大的朋友……
```

`keys` 是关键词，聊到其中一个，这段就会带进对话；`priority` 越大越重要，内容太多放不下时先留重要的。

改完了还有两件事：

1. 打开 `config.toml`，把 `[character]` 里的 `name` 改成他的名字、`player_name` 改成他怎么叫你
2. 重新启动：回到启动它的窗口按 `Ctrl + C` 停掉，再跑一次 `uv run yuwen`。不会的话让 AI 帮你

## 第三步：看看他记不记得

- 和他聊一件具体的小事，比如你今天吃了什么
- 过一阵子再提起相关的事，看他会不会接上
- 页面顶上点「目录」，能看到他记下的每一条。记错了可以改，不想让他想起的可以封起来
- 他说了不像他会说的话：在那条回复上长按（电脑上右键），标一下“他不会这么说”，他以后会注意

## 以后每次怎么打开

在项目文件夹里跑 `uv run yuwen`，再打开那个地址。记不住就跟你的 AI 说：「帮我启动余温」。

## 常见卡住的地方

| 现象 | 怎么办 |
|---|---|
| 启动时说要设置 password | `config.toml` 的 `[auth]` 里，`password` 要改成你自己的，至少 8 位 |
| 浏览器打不开那个地址 | 服务没在运行。看看启动它的窗口是不是关了或者报错了 |
| 发消息后报错、没有回复 | 多半是 API 那三样填错了：地址、Key、模型名对照平台文档再看一遍；也看看账户里还有没有余额 |
| 想让他按意思想起来，不只是对字面 | 见 README「翻阅：embedding 二选一」，要另外填一个 embedding 接口。不填也能用 |
| 想备份、换电脑 | 页面顶上「备份全书（JSON）」导出一份。整个 `data/` 文件夹和 `worldbook/` 一起拷走就是全部 |

## 你的东西在哪里

所有记忆都在你电脑上的 `data/yuwen.db`，扉页在 `worldbook/`，都只在你自己电脑上。余温不会把它们传到别处；你发的每句话会发给你自己选的模型平台。
