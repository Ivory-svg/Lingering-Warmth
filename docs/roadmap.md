# 路线

## 项目路线

1. **开源模板仓库**（现在）：设计文档 + 第一档参考实现 + OOC 守门人
2. **收费服务**：搭建教学、角色 prompt 代写、OOC 调教、世界书整理
3. **托管 App**：有需求再做

前端的其他功能（一起看电影、听音乐、表情包等）不放在这个仓库，有人感兴趣再单独开。

## 参考实现的里程碑

### M1 · 第一档：他记得你

- [x] 配置读取、SQLite 建表与迁移
- [x] OpenAI 兼容客户端（对话 + token 粗估）
- [x] 世界书读取
- [x] 上下文拼装
- [x] `POST /chat` 跑通一轮对话
- [x] 流入：每轮后台写一条记忆
- [x] 交接：超阈值自动交接，新窗口带摘要 + 最后 N 条原话
- [x] OOC 守门人：发出前自查 + `POST /ooc/flag` + 语感笔记进上下文
- [x] `GET /export` 完整导出
- [x] 一个最简单的网页聊天界面，能演示以上功能

### M2 · 第二档：他会想起来

- [ ] embedding 与浮现（取最相近 3–5 条，低确定度要说“好像是”）
- [ ] 遗忘：权重衰减、被想起回升、情绪强的衰减慢
- [ ] “这个忘掉吧”封存
- [ ] 日记工具 + 日历页面 + 日记回复
- [ ] 信物
- [ ] 感应事件

### M3 · 第三档：他会想你

- [ ] 重铸：改写记忆，保留历史；守门人读重铸层
- [ ] 梦境：定时任务
- [ ] 唤醒：定时看一眼，自己决定发不发
- [ ] 纪念日

## 还没想清楚的

- [ ] 交接带多少条原话：先默认 20，等实际用起来再调
- [ ] 情绪怎么标：参考实现先文字 + 数值都存，以后看哪个没用上再删
- [ ] 唤醒多久看一次：给别人的默认值，以及要不要让玩家自己调
- [ ] 本仓库自己用什么协议发布
